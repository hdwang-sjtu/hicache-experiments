# L1 矩阵：18 个 P × 9 个 S（2026-11-02，未完成）

## 目标和固定配置

P=`1k 2k 4k 8k 16k 24k 32k 40k 48k 56k 64k 72k 80k 88k 96k 104k 112k 120k`；
S=`16 32 64 256 512 768 1024 1536 2048`。
仅 L1，Qwen3-8B、BF16 权重/KV、TP=1、输出 1 token，每组合预热一次后收集 10 个正式有效样本，目标 1620 个。
每个样本重新构造 P+S₀，准备请求不进入测量延迟。模型语义质量不评估。

GPU 候选仅 2–3，实际选择 GPU3。上下文和 GPU KV 池为 135168 tokens、CPU KV 池 32 GB、显存预算 0.85；chunk=4096、page size=1、Graph 关闭、overlap 开启。
保持原始 RoPE，仅将 `max_position_embeddings` 扩大为 135168，不启用 YaRN。
HiCache 保留 CPU 备份，以复用空闲检查和原生计时；测量要求 device=P、host=storage=0，H2D tokens/bytes/ops/time 为 0。

## 编排和复现入口

每个组合仍使用两个主脚本；本轮一次性协调器负责种子 0 的组合乱序、逐组合检查点、归档、独立复核及本次容器的清理。
协调器保存在 [v1/audit/run_matrix.py](../../results/l1-matrix-20261102-v1/audit/run_matrix.py)，其中路径、容器 ID 和 PID 属于这次运行。
复现时使用新目录和当前进程信息，不能原样重启旧协调器。启动参数和完整请求命令见 `server/launch.json`、`manifest.json`、`job.json` 与 `audit/`。

宿主机 GPU/CPU 两路各 1 Hz 独立采样，Driver 用 `--telemetry-dir` 关联请求窗口。
前后覆盖边界不超过 2 秒、相邻采样间隔不超过 3 秒、查询不超过 3 秒，实验 GPU 不出现额外计算进程。
环境异常时在计时外暂停，5 分钟未恢复即保存失败状态并停止服务；缓存有效但环境检查失败的尝试仍保留，另有所有缓存有效样本的统计视图。
监控规则和 `owner.json` 格式见[环境监控](../usage.md#环境监控)。原始监控仍无法证明共享主机完全没有干扰。

测量与采样先写 `/tmp/hicache-l1-matrix-20261102-v1` 本机磁盘，组合结束且 Driver 退出后归档到项目 `results/`，避免测量时写 NFS。
`progress.json` 是进行状态；`completion.json` 是终态；完整矩阵须最终独立验收后才能标为完成。
当时估计整轮约 8–10 小时；由于提前失败，没有实际全矩阵耗时可报告。

## 中断与诊断

以下时间均为 Asia/Shanghai：

- 02:40:03，GPU 监控第一次报告 `NVMLError_GpuIsLost`。GPU0 查询失败，旧监控连带丢弃整条采样，GPU3 当时仍完成了预热请求。
- 02:45，等待环境恢复超过 5 分钟，协调器停止本次专用服务，保存失败状态；保留全部样本。
- 随后修正逐卡异常处理：各卡单独记录错误，整体 GPU `ok` 表示选定实验卡能否观测；选定卡故障或采样超时仍会拒绝。
- v2 通过自测和宿主机 NVML 采样验证，但指定 GPU3 编号或 UUID 启动容器均遭到 NVIDIA runtime NVML detection error。
- 内核在 02:54:46 报告 `uvm encountered global fatal error 0x60, requiring os reboot to recover`。
- 宿主机仅选择 GPU3 调用 `cuInit(0)` 返回 `CUDA_ERROR_UNKNOWN (999)`；显式设备/库挂载并使用镜像 CUDA 兼容库的临时容器也无法初始化 CUDA。

这说明恢复受阻已涉及主机的全局 UVM 状态；NVML 可查询到 GPU3 不代表它仍能运行 CUDA。
保存到的内核环形缓冲区从 02:54 开始，初始 Xid 不在其中；GPU0 最初故障的诱因未确定，不能据此断言硬件损坏或归因到其他用户。
诊断证据：[gpu-diagnosis/summary.json](../../results/l1-matrix-20261102-v2/audit/gpu-diagnosis/summary.json)、该目录的原始内核日志、容器日志和宿主机 CUDA 错误码。
