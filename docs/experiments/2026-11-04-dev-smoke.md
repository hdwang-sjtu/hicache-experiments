## 在本机重跑

本机已准备好缓存和运行脚本，在实验仓库目录执行：

```bash
bash results/dev-smoke-20261104-v3/audit/run-dev-smoke.sh \
  "dev-smoke-$(date -u +%Y%m%dT%H%M%SZ)"
```

脚本从当前仓库 HEAD 导出工程快照，使用本地 `dev` 镜像 ID 和 GPU 0，按宿主用户 UID/GID 写入挂载目录。
省略运行名时自动使用 UTC 时间；重跑应使用新名称。脚本保留本机路径，迁移时需调整代码与数据根目录。

本轮 Docker 调用的核心如下；代码快照路径、缓存和结果目录均由上述脚本准备：

```bash
docker run --rm --pull never --gpus device=0 --ipc=host \
  --user "$(id -u):$(id -g)" \
  --mount type=bind,src=/state/partition/hdwang/hicache-dev-smoke/tasks/RUN_ID/project,dst=/experiment,readonly \
  --mount type=bind,src=/state/partition/hdwang/hicache-dev-smoke/cache,dst=/cache \
  --mount type=bind,src=/state/partition/hdwang/hicache-dev-smoke/results,dst=/results \
  --env HOME=/cache/home --env HICACHE_CACHE_DIR=/cache --env RESULTS_DIR=/results \
  --env PYTHONUNBUFFERED=1 --workdir /experiment --entrypoint python3 \
  sha256:a1dc7080e3aa146f5d6ef1744f973b0591d8760d694f19badd9adce6f3fc6303 \
  run_all.py qwen3-8b-smoke --runtime native --run-id RUN_ID
```

用同一个新名称替换示意命令中的两处 `RUN_ID`。容器里无需 Docker daemon，也无需发布服务端口。
本轮镜像已带所需 Python 依赖，没有安装或升级依赖；新环境仍需按总控文档准备依赖。

1. 直接挂载 `/home/hdwang/Workspace/...` 被 Docker daemon 拒绝，退出码 126，未启动总控。该路径位于 NFS，且用户 home 为私有目录；改用本地磁盘运行目录后挂载成功。
2. `dev-smoke-20261104-v2` 在 `preparing_source` 失败：容器访问 GitHub 时出现 `Connection reset by peer`。失败状态和准备日志保留在 [对应归档](../../results/dev-smoke-20261104-v2/)。
3. 在宿主机用已有 Git 对象准备固定基线与补丁缓存，并查询 Hugging Face 固定 revision 的文件元数据，校验后复制已有模型到版本化缓存。原始源码和模型未改动。源码/模型校验细节保存在 `audit/cache-seed.json`。
4. `dev-smoke-20261104-v3` 由未经修改的总控校验并复用这些缓存，完成 GPU 测量。空缓存下的容器联网准备在本机尚未跑通；已准备缓存后的单容器总控流程通过。
